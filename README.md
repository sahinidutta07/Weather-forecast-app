# Weather App

A modern weather application built using HTML, CSS, and JavaScript.

## About the Project

This project is currently under development as part of my web development learning journey. The goal is to build a fully functional weather application with a clean user interface, responsive design, and real-time weather data integration.

## Current Features

* Modern glassmorphism-inspired UI
* Search bar interface
* Weather information card
* Responsive layout
* Interactive user interface using JavaScript
* DOM manipulation for dynamic content updates

## Planned Features

* Real-time weather data using a Weather API
* 5-day weather forecast
* Weather icons
* Humidity and wind speed data
* Feels-like temperature
* Search history
* Dark mode
* Current location weather detection
* Dynamic backgrounds based on weather conditions

## Technologies Used

* HTML5
* CSS3
* JavaScript (Vanilla JS)

## What I Learned

Through this project, I am learning:

* HTML page structure
* CSS styling and layouts
* Responsive design
* Glassmorphism UI design
* JavaScript DOM manipulation
* Event handling
* API integration using Fetch API
